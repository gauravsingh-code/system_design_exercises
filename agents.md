# Agent Rules

## ⚠️ Code Modification Policy

**Do NOT make any changes to any file unless a change is explicitly mentioned/requested in the prompt.**

- If the user asks a question or wants an explanation → only explain, do not edit files.
- If the user says "don't make change" or similar → strictly provide information/guidance only.
- Only modify code when the user clearly says things like: *"make the change"*, *"update the file"*, *"implement this"*, *"apply the fix"*, etc.

---

## Rules Summary

| Situation | Action |
|---|---|
| User asks how to do something | Explain only, no file edits |
| User says "don't make change" | Explain only, no file edits |
| User explicitly asks for a change | Make the change |
| Ambiguous intent | Ask the user to clarify before editing |
